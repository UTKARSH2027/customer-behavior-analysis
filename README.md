# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, customer preferences, spending behavior, and product performance.

The project follows an end-to-end data analytics workflow using **Python for data cleaning, MySQL/SQL for data analysis, and Power BI for interactive visualization and dashboard development.**

The goal is to transform raw customer shopping data into meaningful business insights that can support better decision-making.

---

## 🎯 Objectives

* Clean and preprocess customer shopping data using Python.
* Perform business analysis using SQL and MySQL.
* Identify customer purchasing and spending patterns.
* Analyze product categories and customer behavior.
* Segment customers based on their shopping behavior.
* Create an interactive Power BI dashboard.
* Generate actionable, data-driven business insights.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/customer-shopping-behavior-analysis.git
```

### 2. Data Cleaning

Open:

```text
data_cleaning_with_python.ipynb
```

Run the notebook using **Jupyter Notebook** or **JupyterLab** to perform data cleaning and preprocessing.

### 3. SQL Analysis

Import the cleaned data into **MySQL** and execute:

```text
customer_behavior_sql_queries.sql
```

to perform the required business analysis.

### 4. Power BI Dashboard

Open:

```text
customer_behavior_dashboard.pbix
```

using **Power BI Desktop** to explore the interactive dashboard.
